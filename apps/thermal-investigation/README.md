# THERMAL is now part of the Fusion app

Use **[Fusion Investigator + THERMAL](../../flower-app/README.md)** in `flower-app/`.
The merged app contains the investigator, facility stewards, disclosure gateway,
radial profiles, live Flower launcher, evidence replay, and toy validation sandbox.
It has one environment, one test suite and one frontend.

The former standalone implementation is preserved in Git history. See the
[merge notes](../../flower-app/MERGE.md) for source provenance and fixes.
This application is separate from the TORAX/RL experiments and 3D viewer.
